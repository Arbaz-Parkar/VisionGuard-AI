# Local outputs

Run `scripts/evaluate.py` to compare the patch detector and both classical baselines on the same test images. It writes `metrics.json` and `per_image.csv` under `outputs/metrics/<category>/`. The standalone commands `scripts/evaluate_detector.py` and `scripts/evaluate_classical.py` also remain available for separate reports. Other plots and inspection examples may be added by later workflows. Generated outputs are ignored by Git; no sample metrics or screenshots are included before genuine results exist.
