# Local outputs

Run `scripts/evaluate_detector.py` to create patch-detector reports under `outputs/<category>/metrics.json` and `outputs/<category>/per_image.csv`. Run `scripts/evaluate_classical.py` to create both classical baseline reports under `outputs/classical/<category>/metrics.json` and `per_image.csv`. Other plots and inspection examples may be added by later workflows. Generated outputs are ignored by Git; no sample metrics or screenshots are included before genuine results exist.
