# Local model artifacts

Generated model artifacts and pretrained weights belong here during local development. They are excluded from Git because they may be large and should be reproducibly generated from trusted sources.

Patch detector artifacts use the project's `.npz` format, which stores the memory-bank tensor and JSON metadata without Python pickle. The frozen pretrained ResNet18 weights are not copied into each artifact; recreate the extractor from the recorded TorchVision `IMAGENET1K_V1` weight identifier.

Only load model artifacts generated by this project. Do not load arbitrary user-supplied serialized files.
